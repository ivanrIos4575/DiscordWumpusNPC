🇪🇸 DiscordWumpusNPC

DiscordWumpusNPC es un plugin diseñado para PocketMine-MP 5 que permite añadir un NPC de Discord completamente personalizado a tu servidor de Minecraft Bedrock. El NPC utiliza un modelo 3D personalizado de Wumpus y está pensado para colocarlo en el spawn, lobby o cualquier zona importante del servidor para facilitar que los jugadores se unan a la comunidad de Discord.

🧍 NPC personalizado

El plugin incorpora un NPC basado en el personaje Wumpus, utilizando un modelo 3D personalizado para darle una apariencia mucho más atractiva que un NPC convencional.

Puedes utilizar el NPC como punto de información para tu comunidad y colocarlo en una zona visible del servidor.

🖱️ Interacción mediante clic

Los jugadores pueden acercarse al NPC y hacer clic sobre él para interactuar.

Cuando el jugador interactúa con el NPC, el plugin ejecuta automáticamente la acción configurada, permitiendo mostrarle la información de tu servidor de Discord sin necesidad de que tenga que escribir comandos.

🔗 Enlace de Discord

Una de las funciones principales del plugin es proporcionar rápidamente el enlace de invitación de Discord.

El enlace puede configurarse para utilizar la invitación de tu propia comunidad. De esta manera, solamente tienes que configurar tu enlace una vez y el NPC se encargará de mostrarlo a los jugadores cuando interactúen con él.

Ejemplo:

https://discord.gg/TU-SERVIDOR

💬 Mensajes personalizados

El mensaje mostrado al jugador puede personalizarse para adaptarlo al estilo de tu servidor.

Puedes utilizar mensajes como:

🟣 ¡Únete a nuestro Discord!
💬 Habla con la comunidad, participa en eventos y recibe las últimas novedades.
🔗 discord.gg/TU-SERVIDOR

Esto permite utilizar el plugin con diferentes servidores y comunidades.

🎨 Modelo 3D personalizado

El NPC utiliza un modelo 3D personalizado, permitiendo utilizar diseños diferentes a las entidades estándar de Minecraft.

El modelo está pensado para trabajar junto con sus correspondientes recursos y texturas, ofreciendo una apariencia personalizada para el servidor.

🖼️ Texturas personalizadas

Además del modelo, el plugin permite utilizar texturas personalizadas para que el NPC tenga una apariencia propia.

Esto permite modificar el aspecto visual del NPC y adaptarlo a la identidad de tu servidor.

📍 Ubicación del NPC

El NPC puede utilizarse en una ubicación determinada del servidor, por ejemplo:

* 🏠 Spawn.
* 🌐 Lobby.
* 🛒 Zona de tiendas.
* 📢 Zona de información.
* 🏆 Zona de eventos.
* 💬 Centro de comunidad.

La idea es colocar el NPC en un lugar donde los jugadores puedan encontrarlo fácilmente.

⚙️ Configuración

El plugin está diseñado para que los valores principales puedan modificarse fácilmente mediante su configuración.

Esto permite personalizar elementos como el enlace de Discord y los mensajes mostrados al jugador sin tener que modificar directamente el código del plugin.

🔧 Fácil de utilizar

DiscordWumpusNPC está pensado para ser sencillo de instalar y configurar.

Una vez instalado en tu servidor PocketMine-MP 5, puedes configurar los valores necesarios y utilizar el NPC como acceso directo a tu comunidad de Discord.

🚀 Rendimiento

El plugin está diseñado específicamente para PocketMine-MP 5, manteniendo su funcionamiento centrado en una tarea concreta: proporcionar un NPC personalizado para promocionar y facilitar el acceso al Discord del servidor.

📦 Estructura del plugin

El proyecto utiliza una estructura organizada para separar el código fuente de los recursos:

DiscordWumpusNPC/
├── plugin.yml
├── src/
└── resources/

plugin.yml contiene la información principal del plugin, mientras que src contiene el código PHP y resources contiene los recursos necesarios para la configuración y el funcionamiento del modelo.

🎯 Objetivo del plugin

El objetivo principal de DiscordWumpusNPC es convertir el acceso al Discord en una experiencia más visual y atractiva.

En lugar de limitarse a mostrar un mensaje o pedir a los jugadores que escriban un comando, el servidor puede colocar un Wumpus 3D personalizado en el spawn y utilizarlo como punto de acceso a la comunidad.

🇬🇧 DiscordWumpusNPC

DiscordWumpusNPC is a plugin designed for PocketMine-MP 5 that allows you to add a fully customized Discord NPC to your Minecraft Bedrock server. The NPC uses a custom 3D Wumpus model and is designed to be placed in your spawn, lobby, or any important area of your server to make it easier for players to join your Discord community.

🧍 Custom NPC

The plugin provides a custom NPC based on the Wumpus character, using a custom 3D model to provide a more attractive appearance than a standard Minecraft entity.

The NPC can be used as an information point for your community and placed in a visible area of your server.

🖱️ Click Interaction

Players can approach the NPC and click on it to interact with it.

When a player interacts with the NPC, the plugin automatically performs the configured action, allowing the player to receive your Discord information without needing to type commands.

🔗 Discord Link

One of the main features of the plugin is providing quick access to your Discord invite link.

The link can be configured to use your own community invite. You only need to configure the link once, and the NPC can display it whenever a player interacts with it.

Example:

https://discord.gg/YOUR-SERVER

💬 Custom Messages

The message displayed to players can be customized to match your server’s style.

For example:

🟣 Join our Discord!
💬 Chat with the community, participate in events, and receive the latest news.
🔗 discord.gg/YOUR-SERVER

This allows the plugin to be used by different servers and communities.

🎨 Custom 3D Model

The NPC uses a custom 3D model, allowing you to use designs that are different from standard Minecraft entities.

The model is designed to work together with its required resources and textures, providing a unique visual appearance for your server.

🖼️ Custom Textures

Along with the model, the plugin supports custom textures, allowing the NPC to have its own visual style.

This makes it possible to customize the NPC’s appearance and match your server’s branding.

📍 NPC Location

The NPC can be placed in a specific location on your server, such as:

* 🏠 Spawn.
* 🌐 Lobby.
* 🛒 Store area.
* 📢 Information area.
* 🏆 Event area.
* 💬 Community area.

The goal is to place the NPC somewhere players can easily find it.

⚙️ Configuration

The plugin is designed so that its main values can be easily modified through its configuration.

This allows you to customize things such as the Discord link and messages shown to players without directly modifying the plugin’s source code.

🔧 Easy to Use

DiscordWumpusNPC is designed to be simple to install and configure.

Once installed on your PocketMine-MP 5 server, you can configure the required settings and use the NPC as a direct access point to your Discord community.

🚀 Performance

The plugin is specifically designed for PocketMine-MP 5, keeping its functionality focused on one main purpose: providing a custom NPC to promote and provide access to your server’s Discord community.

📦 Plugin Structure

The project uses an organized structure that separates source code from resources:

DiscordWumpusNPC/
├── plugin.yml
├── src/
└── resources/

plugin.yml contains the main plugin information, src contains the PHP source code, and resources contains the configuration and resources required for the model.

The main goal of DiscordWumpusNPC is to make accessing your Discord server a more visual and engaging experience.

Instead of simply displaying a message or asking players to type a command, your server can place a custom 3D Wumpus at spawn and use it as a visual gateway to your Discord community.
